# 目标回波生成逻辑

## 整体架构

目标回波生成采用分层设计，将运动学计算与回波合成解耦：

```
TargetEngine (编排层)
    │
    ├── TargetKinematics (Layer 1: 运动学与几何量)
    │       → position, velocity, acceleration, range, radial_velocity, gain, RCS
    │
    └── TargetEchoSynthesizer (Layer 2: 回波合成)
    │       → delay, phase, amplitude, echo_matrix
    │
TargetManager (状态管理层，独立模块)
        → 维护目标初始状态，按绝对时间更新当前状态
```

## 模块职责

### TargetManager（目标状态管理器）

**负责**：
- 维护目标初始状态（时刻0）
- 根据运动模型计算指定时刻的位置/速度
- 使用绝对时间方案：从初始状态计算

**不负责**：
- 波位筛选（让 TargetKinematics 的 `skip_out_of_beam_targets` 处理）
- 回波生成

**接口**：
```cpp
class TargetManager {
public:
    void set_targets(const std::vector<TargetState>& targets);
    void update_to_time(Scalar current_time_s);
    const std::vector<TargetState>& get_current_targets() const;
};
```

**时间推进逻辑**：
```cpp
void TargetManager::update_to_time(Scalar t_s) {
    for (size_t i = 0; i < initial_targets_.size(); ++i) {
        const auto& init = initial_targets_[i];
        auto& curr = current_targets_[i];

        switch (init.motion_model) {
        case MotionModel::Stationary:
            curr.position_m = init.position_m;
            curr.velocity_mps = Vec3::Zero();
            break;
        case MotionModel::ConstantVelocity:
            curr.position_m = init.position_m + init.velocity_mps * t_s;
            curr.velocity_mps = init.velocity_mps;
            break;
        case MotionModel::ConstantAcceleration:
            curr.position_m = init.position_m + init.velocity_mps * t_s
                            + 0.5 * init.acceleration_mps2 * t_s * t_s;
            curr.velocity_mps = init.velocity_mps + init.acceleration_mps2 * t_s;
            break;
        }
        // 其他属性保持不变
    }
}
```

### TargetKinematics（Layer 1: 运动学与几何量）

**负责生成**：
- 位置 `position_m`
- 速度 `velocity_mps`
- 加速度 `acceleration_mps2`
- 距离 `range_m`（派生量）
- 径向速度 `radial_velocity_mps`（派生量）
- 径向加速度 `radial_acceleration_mps2`（派生量）
- 天线增益 `gain_linear`
- RCS `sigma_m2`（Swerling起伏模型）

**输出结构**：
```cpp
struct TargetSnapshot {
    Scalar slow_time_s;                // 脉冲时刻（慢时间）
    Vec3 position_m;                   // 目标位置
    Vec3 velocity_mps;                 // 目标速度
    Vec3 acceleration_mps2;            // 目标加速度
    Scalar range_m;                    // 目标距离
    Scalar radial_velocity_mps;        // 径向速度
    Scalar radial_acceleration_mps2;   // 径向加速度
    Scalar gain_linear;                // 天线增益
    Scalar rcs_m2;                     // RCS值（已起伏）
};
```

**运动模型计算**：
```cpp
Vec3 position_st(const TargetState& target, Scalar t_s) {
    switch (target.motion_model) {
    case MotionModel::Stationary:
        return target.position_m;
    case MotionModel::ConstantVelocity:
        return target.position_m + target.velocity_mps * t_s;
    case MotionModel::ConstantAcceleration:
        return target.position_m + target.velocity_mps * t_s
               + 0.5 * target.acceleration_mps2 * t_s * t_s;
    }
}
```

**RCS起伏模型（Swerling）**：
| 类型 | 起伏特性 | 分布模型 |
|------|----------|----------|
| Swerling0 | 无起伏 | 固定值 |
| Swerling1 | 慢起伏（CPI内不变） | 指数分布 |
| Swerling2 | 快起伏（脉冲间独立） | 指数分布 |
| Swerling3 | 慢起伏 | Gamma分布(k=2) |
| Swerling4 | 快起伏 | Gamma分布(k=2) |

### TargetEchoSynthesizer（Layer 2: 回波合成）

**负责生成**：
- 延时 `delay_s = 2R/c`
- 相位 `φ = -4πR(t)/λ`（多普勒相位）
- 幅度（雷达方程）
- 回波矩阵（写入距离bin）

**关键计算**：
```cpp
// 延时计算
const Scalar delay_s = (2.0 * sample.range_m) / C;
const Scalar fast_time_s = delay_s - tau_ref_s;
const int delay_idx = static_cast<int>(std::llround(fast_time_s * fs_hz));

// 相位计算（使用实际位置计算正确的多普勒）
phase = -4.0 * PI * current_range_m / lambda_m;

// 幅度计算（雷达方程）
amplitude = std::sqrt(tx_power_w * gain_linear * gain_linear
                      * lambda_m * lambda_m * rcs_m2
                      / (std::pow(4.0 * PI, 3) * std::pow(range_m, 4) * loss_linear));
```

### TargetEngine（编排层）

**负责**：
- 接收已准备好的 TargetList
- 编排 TargetKinematics 和 TargetEchoSynthesizer
- 生成一个 CPI 的目标回波

**不负责**：
- 目标状态更新（TargetManager负责）
- 目标筛选
- 轨迹推进

## 主循环集成

```cpp
MainLoop(radar):
    // 初始化
    TargetManager target_manager;
    target_manager.set_targets(radar.target.targets);  // 初始状态

    Scalar current_time = 0.0;
    const Scalar cpi_duration = radar.pulses_per_cpi / radar.prf_hz;

    Precompute waveform / antenna tables

    for each scan:
        for each CPI:
            beam = scan_model.update(current_time)  // 每个CPI一个波位

            // 更新目标状态到当前时刻
            target_manager.update_to_time(current_time)

            // 获取当前目标（暂不做波位筛选）
            TargetList active_targets = target_manager.get_current_targets()

            // 生成回波
            y_target  = target_engine.generate(active_targets, beam, radar, tx_waveform)
            y_clutter = clutter_engine.generate(scene, beam, radar)
            y_noise   = noise_engine.generate(radar)
            y_rx      = y_target + y_clutter + y_noise
            writer.write_iq(y_rx)

            // 时间推进
            current_time += cpi_duration
```

## 数据流

```
TargetState (初始状态)
    │
    ↓ TargetManager.update_to_time(current_time)
    │
TargetState (当前时刻状态)
    │
    ↓ TargetKinematics.generate_trajectory(target, beam, radar)
    │
TargetTrajectory (CPI内逐脉冲快照)
    │   - snapshots[pulse_idx]: position, velocity, range, gain, RCS
    │
    ↓ TargetEchoSynthesizer.synthesize(trajectory, beam, radar, waveform)
    │
ComplexMatrix (CPI回波矩阵)
    │   - [pulse_idx, range_bin]: IQ采样
    │
    ↓ TargetEngine.generate(targets, beam, radar, waveform)
    │
ComplexMatrix (多目标叠加回波)
```
