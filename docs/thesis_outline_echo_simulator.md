# 《对海监视雷达回波模拟器的设计与实现》论文规划

## 1. 论文整体定位

论文题目为：

```text
对海监视雷达回波模拟器的设计与实现
```

论文不应定位为单纯的软件工程说明，也不应只写海杂波算法。更合适的主线是：

```text
围绕对海监视雷达回波模拟的实时性和真实性需求，
设计并实现一个复基带回波模拟器；
重点解决海杂波非高斯统计建模、多普勒谱控制和 GPU 实时生成问题。
```

论文核心内容可以概括为：

```text
雷达回波建模 + 海杂波生成方法 + GPU 实时实现 + 实验验证
```

## 2. 模拟器完成边界

本文模拟器建议做到以下程度：

1. 支持配置雷达参数、扫描参数、目标参数、杂波参数和噪声参数。
2. 能按 PRT 生成复基带距离向回波。
3. 回波包括目标回波、海杂波和热噪声。
4. 海杂波支持非高斯幅度分布和多普勒谱控制。
5. 能导出一圈扫描数据并显示距离-方位图或 PPI。
6. 能完成幅度统计、功率谱和实时性验证。
7. 能在 GPU 平台上给出实时生成性能测试结果，重点关注 Jetson AGX Orin。

不建议把范围扩展到以下内容：

- 完整雷达信号处理链。
- 复杂 CFAR、检测、跟踪算法。
- 完整显控软件。
- 完整 PCIe 驱动开发。
- 真实海图/GIS 地形融合。

后端处理可以作为数据输出对象和应用场景说明：

```text
本文模拟器输出可供后端信号处理板卡或算法模块测试使用；
检测、跟踪和显控不作为本文重点。
```

## 7. 第 4 章 基于 GPU 的海杂波实时生成方法

第 4 章是论文核心章，建议控制为 4 个小节：

```text
4.1 海杂波散射单元与非高斯分布建模
4.2 基于 Counter-based RNG 的相关杂波生成
4.3 K 分布 SIRP 杂波生成方法
4.4 GPU 并行映射与单 PRT 生成流程
```

### 4.1 海杂波散射单元与非高斯分布建模

重点写：

- 距离-方位 patch 划分。
- patch 平均功率计算。
- patch 级分布建模。
- ZMNL 方法生成 Weibull 和 LogNormal。
- Rayleigh、Weibull、LogNormal 的关系。
- patch 级变换后再按天线方向图和距离权重相干叠加。

关键表述：

```text
非高斯分布应属于海面散射单元本身，而不是对最终距离单元回波进行后处理。
因此本文在 patch 级完成幅度分布建模，再进行相干叠加。
```

### 4.2 基于 Counter-based RNG 的相关杂波生成

重点写：

- 传统 FIR 相关杂波需要保存历史状态。
- Counter-based RNG 根据距离、方位、脉冲号和随机源编号直接生成任意历史白噪声。
- FIR 滤波形成目标多普勒谱。
- 不需要保存 speckle delay line。
- 适合 GPU 并行，且任意 PRT 可复现。

可以突出为本文的主要方法贡献：

```text
将相关海杂波生成中的历史白噪声存储问题，转化为基于索引的按需随机样本计算问题。
```

### 4.3 K 分布 SIRP 杂波生成方法

重点写：

- K 分布可视为慢变 texture 与快变 speckle 的乘积。
- speckle 负责复高斯快变散射和多普勒谱。
- texture 负责慢变强度调制和重尾幅度统计。
- texture 可由低通或 AR 过程生成，再通过 Gamma 映射得到。
- 最终 patch 杂波为：

```text
K clutter = sqrt(texture) * speckle
```

该节可以作为 K 分布区别于普通 ZMNL 方法的重点。

### 4.4 GPU 并行映射与单 PRT 生成流程

GPU 架构介绍要服务于本文方法，不写成 CUDA 教程。

重点写：

- 一个 PRT 对应一次 GPU kernel。
- 一个 GPU thread 负责一个距离单元。
- 线程内部遍历当前波束 active patch。
- active patch 集合在同一 PRT 内复用。
- FIR 系数在所有线程中复用。
- 输出当前 PRT 的距离向复回波。

关键表述：

```text
海杂波生成过程中，不同距离单元之间不存在数据相关性。
因此本文将距离单元作为 GPU 线程并行维度，
将一个 PRT 的海杂波生成映射为一次 CUDA kernel 调用。
```

## 14. 实验结果建议组织

第 5 章实验结果建议按“先正确性，再效果图，最后实时性”的顺序组织：

```text
1. 单 patch 幅度分布验证

3. 一圈 PPI 图像验证
```

```text

再证明空间扫描图像是合理的；
最后证明生成速度满足实时性要求。
```
