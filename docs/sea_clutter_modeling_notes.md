# 海监视雷达海杂波建模方案与后续扩展备忘

## 1. 当前 baseline 思路

当前海杂波模拟采用“全局海况 + 距离-方位网格 + 当前波束 active patch 叠加”的方案。

基本假设为：

- 仿真海域全图都存在潜在海杂波。
- 每个海面散射单元由距离单元和方位 patch 共同定义。
- 每个 PRT 只计算当前波束照射范围内贡献显著的 active patch。
- 每个 patch 的平均功率由后向散射系数、patch 面积和雷达方程决定。
- 每个 patch 的时间相关性由统一多普勒谱控制。
- 每个 patch 的幅度统计由 Rayleigh、Weibull、LogNormal 或 K 分布模型控制。
- 当前距离单元回波由多个 active patch 按天线方向图和距离权重相干叠加得到。

这个 baseline 适合作为海监视雷达的第一版杂波模拟框架。它不是简单地让所有距离单元拥有同样功率，因为平均功率已经随距离、擦地角和 patch 面积变化；全局一致的是海况、幅度分布参数和多普勒谱参数。

### 1.1 平均幅度图的数据组织

后向散射系数不是固定常数。对于每个距离单元，它受到以下因素影响：

- 雷达载频和波长。
- 海况等级。
- 天线高度和目标海面位置共同决定的擦地角。
- 距离单元对应的 patch 面积。
- 雷达方程中的距离衰减和系统损耗。

当前 Morchin baseline 使用波长、海况和擦地角。极化方式可在后续替换或扩展后向散射模型时接入。

运行时后续步骤使用的是幅度，因此初始化阶段直接保存每个 patch 的平均回波幅度：

```text
patch_amplitude_map[az_idx][range_idx] = sqrt(patch_power)
```

设备端布局采用：

```text
[az][range]
```

这样，在固定活动方位 patch 下，相邻 GPU thread 读取相邻距离单元，显存访问连续。

当前均匀海面模式下，先根据距离、擦地角和 patch 面积计算一条距离向幅度剖面，再沿全部方位复制到二维幅度图中：

```text
range_amplitude[range_idx]
    -> patch_amplitude_map[all az_idx][range_idx]
```

二维存储不是为了在均匀海面模式下重复计算，而是为后续空间非均匀场景保留统一入口。加入区域 mask 后，可以直接对指定区域的二维幅度单元做置零、衰减或增强，不需要改变杂波生成 kernel 的主体流程。

### 1.2 天线方向图权重的数据组织

天线方向图拆分为方位权重和俯仰权重：

| 权重 | 依赖因素 | 处理方式 |
|---|---|---|
| 方位幅度权重 | 当前波束方位与 patch 方位之差 | CPU 每个 PRT 构建 active patch 列表时计算 |
| 俯仰幅度权重 | 当前波束俯仰与距离单元对应俯仰角之差 | 对每个距离单元计算一条距离向权重表 |

每个 patch 的最终幅度系数为：

```text
patch_amplitude
* az_amplitude_weight
* el_amplitude_weight
* peak_amplitude_weight
```

俯仰权重只依赖距离单元，不需要扩展为二维表。普通逐 PRT 路径在波束俯仰变化时更新一次距离向表；异步双缓冲路径为两个 slot 分别保留距离向权重，避免并发覆盖。

## 2. 全局生成还是局部生成

对海监视雷达而言，更合理的理解是：

```text
全海面都有潜在杂波，但当前 PRT 只生成当前波束照射到的部分。
```

因此，当前“全图都有杂波 + 波束筛选 active patch”的策略是合理的。它既符合雷达扫描过程，也避免每个 PRT 遍历全方位 patch。

后续若需要更真实的场景，可在全局海面基础上增加空间 mask：

- 海面区域：生成海杂波。
- 陆地区域：不生成海杂波，或切换到地杂波模型。
- 遮挡区域：无回波或衰减。
- 局部区域：覆盖全局海况或分布参数。

## 3. 散射单元划分对参数的影响

散射单元划分会直接影响平均功率：

```text
RCS = sigma0 * patch_area
```

因此方位 patch 划得更细时，单个 patch 面积减小，单个 patch 的平均功率也应减小。当前使用 Morchin 模型计算后向散射系数，再乘以 patch 面积作为等效 RCS，这个方向是正确的。

幅度分布和功率谱参数是否随网格变化，可以分阶段处理：

1. 工程 baseline  
   同一海况下所有 patch 使用同一组分布参数和多普勒谱参数，patch 面积只影响平均功率。

2. 更真实模型  
   分布参数可随分辨率、擦地角、海况等变化。一般来说：

```text
单元越小 -> 散射点数量越少 -> 非高斯/重尾更明显
单元越大 -> 多散射点叠加 -> 更接近 Rayleigh / 复高斯
```

因此 K 分布形状参数、Weibull 形状参数、LogNormal 参数都可以作为后续的空间/分辨率相关参数。

## 4. 与机载雷达杂波建模的区别

机载雷达中常需要现场计算每个 patch 的多普勒谱，主要原因是平台高速运动使杂波多普勒强烈依赖观测几何。

机载情况下，每个 patch 的多普勒中心和谱展宽通常与以下因素有关：

- 平台速度。
- 雷达波长。
- 视线方向。
- 方位角和俯仰角。
- 距离和地面几何。

因此机载雷达常出现 clutter ridge，需要按距离-方位或角度-多普勒几何逐 patch 计算多普勒中心和谱宽。

当前模型面向海监视雷达，可先按岸基或舰载低速扫描场景处理。此时海杂波多普勒主要来自海面运动、风浪和经验谱宽，使用全局多普勒谱作为 baseline 是可接受的。

若后续扩展到机载或高速平台，应在当前距离-方位 patch 框架上增加：

```text
doppler_center(r, az)
doppler_sigma(r, az)
```

也就是让每个 patch 拥有自己的几何多普勒参数。

## 5. 当前全局参数是否需要改变

当前全局一套参数是合理的第一阶段选择：

- 全局海况。
- 全局幅度分布类型。
- 全局分布参数。
- 全局多普勒谱宽。
- 基于距离、擦地角和 patch 面积变化的平均功率。

也就是说，当前不是所有 patch 完全相同，而是：

```text
平均功率随空间变化；
统计分布类型和谱参数全局一致。
```

这适合用于验证 GPU 实时生成框架、ZMNL/SIRP 分布建模、功率谱成形和 PPI 显示。

## 6. 后续空间非均匀扩展方向

后续可以在全局参数基础上增加区域化参数覆盖。建议按以下层次推进。

### 6.1 空间 mask

优先支持区域 mask：

- 海面：使用海杂波模型。
- 陆地：无海杂波，或后续接入地杂波。
- 指定矩形/多边形区域：局部参数覆盖。

第一阶段可以直接在二维幅度图上实现 mask：

```text
mask = 0      -> 关闭该区域海杂波
0 < mask < 1 -> 衰减该区域海杂波
mask > 1     -> 增强该区域海杂波

patch_amplitude_map[az][range] *= mask[az][range]
```

后续如果需要让局部区域改变海况、分布参数或多普勒谱，再增加对应的二维参数图。

### 6.2 局部海况变化

支持不同区域使用不同海况或散射强度修正：

- 不同区域 sea state 不同。
- 不同区域 sigma0 乘局部修正因子。
- 局部区域回波增强或减弱。

典型场景：

- 远海与近岸海况差异。
- 航迹尾流区域。
- 雨区或局部风场变化区域。
- 岛岸附近混合区域。

### 6.3 谱参数空间变化

进一步支持多普勒谱参数随空间变化：

```text
doppler_center = doppler_center(r, az)
doppler_sigma  = doppler_sigma(r, az)
```

对岸基/舰载海监视雷达，可先考虑海况、风速、风向和观测方位夹角对谱宽的影响。对机载雷达，应引入平台运动几何。

### 6.4 分布参数空间变化

进一步支持幅度分布参数随区域、分辨率和擦地角变化：

- K 分布形状参数随海况和分辨率变化。
- Weibull 形状参数随区域变化。
- LogNormal 参数随局部散射强度变化。

这类扩展可用于模拟更真实的非均匀重尾杂波。

## 7. 推荐汇报表述

当前阶段可表述为：

```text
采用全局海况参数，基于距离-方位网格划分海面散射单元。
每个散射单元的平均功率由 Morchin 后向散射系数和单元面积决定。
每个散射单元的慢时间相关性由统一多普勒谱控制。
每个散射单元的幅度分布由 Rayleigh / Weibull / LogNormal / K 模型控制。
当前波束照射范围内的多个散射单元按天线方向图和距离权重相干叠加。
```

后续扩展可表述为：

```text
在全局参数模型基础上，引入空间非均匀海况模型。
通过区域 mask 和局部参数覆盖，使海况、分布参数、多普勒谱宽和 RCS 修正因子随空间位置变化。
对于机载或高速平台场景，可进一步引入基于观测几何的 patch 级多普勒中心和谱宽计算。
```
