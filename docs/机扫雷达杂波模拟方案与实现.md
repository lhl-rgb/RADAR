# 机扫雷达回波模拟器 - 杂波生成方案与实现

## 一、项目概述

本项目将雷达回波模拟器从**相控阵雷达**改造为**岸基机械扫描雷达**。核心变化：

- 波束以 PRT 为单位更新（非 CPI）
- 杂波使用瑞利分布（已去掉 K 分布）
- 删除所有相控阵相关代码
- 删除所有 JSON 序列化（改用 gRPC 传参）

---

## 二、杂波生成方案

### 2.1 核心思想

**距离-方位二维杂波单元建模，每个单元有独立 AR(1) 状态；天线每个 PRT 按方向图对附近方位单元加权叠加，输出一个 PRT 的距离向复 I/Q 回波。**

```
静态杂波场景 + 机械扫描天线 + PRT级时间推进 = 连续机扫杂波回波
```

### 2.2 杂波场景划分

建立二维杂波网格 `state(r, m)`：

- **r** = 0, 1, ..., N_R-1  距离单元（按距离分辨率划分）
- **m** = 0, 1, ..., N_θ-1  方位单元（按角分辨率划分，默认 0.25°）

| 维度 | 划分方式 | 默认值 |
|------|----------|--------|
| 距离 | ΔR = c/(2×BW) | 6m，N_R = 8448 |
| 方位 | Δθ = 0.25° | N_θ = 1440 |

每个杂波单元 (r, m) 有：
- **平均功率** `P_c(r, m)` — 由 Morchin 散射模型 + 雷达方程算出
- **AR(1) 状态** `x(r, m)` — 脉冲间相关的复高斯随机过程
- **上次更新时间** `last_update(r, m)` — 用于跳步更新

### 2.3 相关性构建

| 维度 | 是否构建 | 方法 |
|------|----------|------|
| 距离维 | 不构建 | 不同距离单元独立 |
| 脉冲维 | 构建 | AR(1) 模型 |
| 方位维 | 构建 | 天线方向图扫描加权叠加 |
| 幅度分布 | 瑞利 | 复高斯 I/Q |

### 2.4 AR(1) 模型

**基本递推：**

```
x_k(r,m) = ρ × x_{k-1}(r,m) + sqrt(1-|ρ|²) × w_k(r,m)
```

其中 `w_k(r,m) ~ CN(0,1)` 是独立复高斯白噪声。

**相关系数 ρ 的计算：**

```
|ρ| = exp(-2π² × σ_f² × PRI²)    ← 高斯功率谱的离散自相关
ρ = |ρ| × exp(j × 2π × f_d × PRI)  ← 加入多普勒中心偏移
```

| 参数 | 含义 | 默认值 |
|------|------|--------|
| σ_f | 多普勒谱标准差 | 20 Hz |
| f_d | 多普勒中心频率 | 0 Hz |
| PRI | 脉冲重复间隔 | 0.625 ms |
| \|ρ\| | 脉冲间相关系数 | 0.9969 |

**跳步更新（波束离开后再次扫到时）：**

```
间隔 L 个脉冲：
x_k = ρ^L × x_{k0} + sqrt(1-|ρ|^(2L)) × w
```

### 2.5 天线方向图

使用高斯近似的**电压方向图**：

```
G_v(Δθ) = exp(-2ln2 × (Δθ/θ_B)²)
```

其中 θ_B 是 3dB 波束宽度，由口径推导：`θ_B = 0.886 / aperture_width_lambda`（弧度→度）。

### 2.6 杂波功率模型（Morchin + 雷达方程）

对每个杂波单元 (r, m)：

```
1. 计算掠射角：grazing = atan(antenna_height / ground_range)
2. Morchin 后向散射系数：σ0 = f(grazing, wavelength, sea_state)
3. 杂波斑块面积：A = ΔR × R × Δθ_rad
4. 接收功率：P_c = (Pt × λ² × σ0 × A) / ((4π)³ × R⁴ × L)
```

注意：P_c 不含天线增益 G²，因为方向图加权在叠加时做。

### 2.7 单脉冲回波生成公式

```
y_k(r) = Σ_m [ sqrt(P_c(r,m)) × G_v(θ_m - θ_ant(k)) × x_k(r,m) ]
```

只对波束附近的方位单元求和（计算窗口 = 1.5 × 波束宽度）。

## 三、数据更新流程

### 3.1 初始化阶段（程序启动时）

```
1. 分配状态矩阵：state[N_R × N_θ]，power[N_R × N_θ]，last_update[N_R × N_θ]
2. 计算功率矩阵：对每个 (r, m) 计算 Morchin σ0 + 雷达方程 → P_c(r,m)
3. 预计算 sqrt(P_c) 矩阵
4. 初始化状态：每个杂波单元赋独立 CN(0,1) 随机初值
5. 计算 AR 参数：|ρ|、sqrt(1-|ρ|²)
6. last_update 全部设为 -1（表示未更新）
```

### 3.2 每个 PRT 的更新流程

```
输入：第 k 个 PRT，当前波束方位 θ_ant(k)
输出：y_k = [y_k(0), y_k(1), ..., y_k(N_R-1)]

步骤：

1. 确定当前波束覆盖的方位单元
   中心方位单元 = azimuth_to_cell(θ_ant)
   活动窗口 = [中心 - 半窗口, 中心 + 半窗口]
   半窗口 = int(1.5 × 波束宽度 / 角分辨率) + 1

2. 对每个活动方位单元 m：
   a. 计算天线方向图增益 G_v(θ_m - θ_ant)
   b. 如果 G_v < 1e-6，跳过（方向图权重太小）
   c. 对每个距离单元 r：
      - 计算跳步间隔 L = k - last_update(r,m)
      - 如果 L > 0：
        · 生成复高斯噪声 w（Box-Muller 快速 hash）
        · 如果 L == 1：x = ρ × x + sqrt(1-|ρ|²) × w
        · 如果 L > 1：x = ρ^L × x + sqrt(1-|ρ|^(2L)) × w
        · 更新 last_update(r,m) = k
      - 累加：y_k(r) += sqrt(P_c(r,m)) × G_v × x(r,m)

3. 输出 y_k
```

### 3.3 数据流图

```
                    ┌──────────────┐
                    │  天线配置     │
                    │  (口径、增益) │
                    └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │  天线模型     │
                    │  (方向图 G_v) │
                    └──────┬───────┘
                           │
┌──────────┐        ┌──────▼───────┐        ┌──────────┐
│ 雷达参数  │───────→│   杂波地图    │←───────│ 散射模型  │
│ Pt,λ,h,R │        │  state(r,m)  │        │ Morchin σ0│
└──────────┘        │  power(r,m)  │        └──────────┘
                    └──────┬───────┘
                           │ 每PRT输出
                    ┌──────▼───────┐
                    │ 仿真引擎      │
                    │              │
                    │ 杂波 + 目标   │
                    │   + 噪声     │
                    │   = 总回波    │
                    └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │  输出 PulseResult │
                    │  (脉冲序号、方位角、回波) │
                    └──────────────┘
```

## 四、代码结构

### 4.1 文件清单

| 文件 | 作用 |
|------|------|
| `clutter_map.h` | 杂波地图类定义（AR(1) 状态矩阵、功率矩阵） |

### 4.2 关键类

**ClutterMapConfig** — 杂波配置：

```cpp
struct ClutterMapConfig {
    bool enabled = true;
    Scalar angular_resolution_deg = 0.25;  // 方位角分辨率

    Scalar doppler_sigma_hz = 20.0;        // 多普勒谱宽
```

**ClutterMap** — 杂波地图核心类：

```cpp
class ClutterMap {
    // 配置
    void set_config(const ClutterMapConfig& cfg);

    Complex rho_;                      // AR 相关系数
    // ...
};
```

### 4.3 内存布局

```
state_[r * num_az_cells + m]

r = 距离单元索引（外层）
m = 方位单元索引（内层，连续内存）

例：r=100, m=50 的状态 = state_[100 * 1440 + 50]
```

## 五、性能特征

### 5.1 内存占用

| 参数 | 8448距离 × 1440方位 |
|------|---------------------|
| state_ (Complex) | 97 MB |
| power_ (Scalar) | 48 MB |
| sqrt_power_ (Scalar) | 48 MB |
| last_update_ (int) | 48 MB |
| **总计** | **~241 MB** |

### 5.2 计算量

| 项目 | 值 |
|------|-----|
| 每 PRT 活动方位单元 | ~30（1.5×波束宽度窗口）|
| 每 PRT 更新单元数 | 30 × 8448 = 253K |
| 每圈脉冲数 | 3600 |
| 每圈总更新次数 | 9.12 亿 |

### 5.3 实测性能（8448距离 × 1440方位 × 3600脉冲）

| 阶段 | 耗时 |
|------|------|
| 初始化 | ~500 ms |
| 一圈仿真 | ~50-100 s |
| 实时因子 | ~0.02-0.04x（比实时慢 25-50 倍）|

**结论：当前纯 CPU 实现无法达到实时性。** 主要瓶颈是内存带宽（97MB 状态矩阵的随机访问）。后续可用 CUDA 加速。

## 六、与旧方案的对比

| | 旧方案（FFT预生成） | 新方案（AR(1)逐脉冲） |
|---|---|---|
| 距离单元间相关性 | 完全相关（太假） | 独立（正确） |
| 脉冲间相关性 | FFT频域整形 | AR(1) 递推 |
| 方位相关性 | bin内无变化 | 天线方向图扫描 |
| 天线方向图参与 | 不参与 | 直接参与叠加 |
| 实时性 | 快（查表） | 慢（实时计算） |
| 物理真实性 | 差 | 好 |
| 可扩展性 | 差 | 好（可加遮蔽、地形等）|

---

## 七、后续优化方向

1. **CUDA 加速**：将 AR(1) 更新和加权叠加放到 GPU 上并行计算
2. **内存布局优化**：转置为 `[az × range]` 布局，改善缓存局部性
3. **向量化**：使用 SIMD 指令加速内层循环
4. **分块计算**：将状态矩阵分块，每块放入 L2 缓存
