# GPU 加速海杂波生成方案汇报大纲

## 1. 汇报定位

本次汇报聚焦于回波模拟器中的核心模块：

```text
基于 GPU 的海杂波实时生成方法
```

不展开完整雷达回波模拟器所有模块，只围绕海杂波生成说明：

- 为什么海杂波生成需要 GPU 加速。
- 当前海杂波模型如何建立。
- 如何生成不同幅度分布和功率谱特性的杂波。
- 如何按 PRT 实时生成。
- 当前验证结果和后续计划。

建议汇报时长控制在 15 到 20 分钟。

## 2. 汇报整体结构

建议按以下 7 个部分组织：

```text
1. 研究背景与问题
2. 海杂波生成需求
3. 传统方法及存在问题
4. 本文 GPU 海杂波生成方案
5. 关键算法设计

7. 后续工作计划
```

## 3. 第一部分：研究背景与问题

### 3.1 背景

对海监视雷达回波模拟器需要为后端信号处理算法或硬件平台提供可控输入。真实海试存在成本高、条件不可控、重复性差等问题，因此需要软件回波模拟器生成可重复的目标、杂波和噪声回波。

### 3.2 海杂波的重要性

海杂波是对海监视雷达中最主要的环境干扰之一，直接影响：

- 小目标检测。
- 恒虚警处理。
- 动目标显示。
- 后端处理算法测试。

### 3.3 主要难点

海杂波生成的难点包括：

- 幅度分布具有非高斯特性。
- 慢时间序列需要满足指定功率谱。
- 距离-方位散射单元数量多。
- 每个 PRT 都要实时生成距离向复回波。
- 需要保证随机结果可复现。

## 4. 第二部分：海杂波生成需求

### 4.1 功能需求

海杂波模块需要支持：

- 按 PRT 生成距离向复回波。
- 支持扫描波束下的方位照射变化。
- 支持多种海杂波幅度分布。
- 支持多普勒功率谱控制。
- 支持一圈扫描数据导出和 PPI 显示。
- 支持实时生成性能测试。

### 4.2 当前支持的分布

当前重点考虑四类海杂波幅度分布：

- 瑞利分布。
- Weibull 分布。
- 对数正态分布。
- K 分布。

其中，瑞利分布对应复高斯杂波；Weibull 和对数正态可通过 ZMNL 方法生成；K 分布采用 SIRP 思路，由慢变 texture 和快变 speckle 共同构成。

### 4.3 实时性需求

对实时回波模拟而言，每个 PRT 的生成时间应尽量小于 PRT 间隔。以 PRF 为 1600 Hz 为例：

```text
PRT = 1 / 1600 = 625 us
```

因此海杂波生成模块需要在数百微秒量级完成单个 PRT 的生成。

## 5. 第三部分：传统方法及存在问题

### 5.1 预生成方法

一种方法是提前生成完整杂波数据，运行时直接读取。这种方法简单，但存在：

- 数据量大。
- 不利于长时间仿真。
- 不便于在线修改参数。
- 不适合多次蒙卡和多场景测试。

### 5.2 公共长序列随机起点方法

另一种方法是生成一条具有指定谱形的长杂波序列，不同距离单元从不同随机起点读取。

该方法计算量较低，但问题是：

- 不同距离单元本质上来自同一条序列。
- 距离单元间可能存在非物理相关性。
- 不适合表达每个海面散射单元独立散射的物理过程。

### 5.3 状态递推方法

FIR 或 IIR 递推方法可以生成相关杂波，但如果为每个距离-方位 patch 保存历史状态，状态量会随下式增长：

```text
N_range x N_azimuth x filter_length
```

当距离单元数、方位 patch 数和滤波器长度较大时，存储和更新开销较高。

## 6. 第四部分：本文 GPU 海杂波生成方案

### 6.1 总体思路

本文采用：

```text
距离-方位 patch 建模
+ Counter-based RNG
+ FIR 多普勒谱成形
+ ZMNL/SIRP 幅度分布建模
+ GPU 并行计算
```

每个海面 patch 生成具有指定统计特性和功率谱的复随机序列，当前波束照射到的多个 patch 按天线方向图和距离权重相干叠加，得到当前 PRT 的距离向海杂波回波。

### 6.2 距离-方位 patch 建模

海面被划分为距离和方位两个维度：

```text
距离单元 r
方位 patch a
```

每个 patch 表示一个等效海面散射单元。其平均功率由：

- 后向散射系数。
- patch 面积。
- 雷达方程。
- 距离衰减。

共同决定。

### 6.3 当前 PRT active patch

全海面可以存在潜在杂波，但某个 PRT 中只需计算当前波束照射范围内贡献显著的方位 patch。

因此每个 PRT 的生成流程为：

```text
当前波束指向
-> 确定 active patch
-> GPU 并行生成各距离单元回波
-> 输出当前 PRT 距离向复回波
```

### 6.4 按 PRT 实时生成

与预生成整圈或整段时间序列不同，本方法每次只生成当前 PRT 的回波：

```text
输入：当前 PRT 编号、波束指向、杂波参数
输出：当前 PRT 的距离向复回波
```

这种方式更适合在线仿真和后端实时测试。

## 7. 第五部分：关键算法设计

### 7.1 Counter-based RNG

Counter-based RNG 的核心思想是随机样本由索引直接确定：

```text
随机样本 = F(seed, 距离编号, 方位编号, 随机源编号, 脉冲编号)
```

优点：

- 不需要保存完整随机序列。
- 可以直接生成任意历史脉冲的样本。
- 任意 PRT 可复现。
- 不同 GPU 线程可以独立生成随机样本。

### 7.2 多普勒谱成形

对每个 patch，先生成复白高斯序列，再通过 FIR 滤波形成目标多普勒谱：

```text
白复高斯序列 -> FIR 谱成形 -> 相关 speckle
```

由于历史白噪声样本可由 counter 直接计算，因此不需要保存 speckle 的长 delay line。

### 7.3 ZMNL 分布建模

Weibull 和对数正态分布采用 ZMNL 方法生成：

```text
相关复高斯 speckle
-> 幅度非线性映射
-> 保留原相位
-> 非高斯复杂波
```

这种方法可以在保持时间相关性的基础上改变幅度统计特性。

### 7.4 K 分布 SIRP 建模

K 分布采用 SIRP 思路：

```text
K 分布杂波 = sqrt(texture) x speckle
```

其中：

- speckle 表示快变复高斯散射。
- texture 表示慢变强度调制。

texture 可通过慢变高斯过程和 Gamma 映射得到，从而形成重尾幅度分布。

### 7.5 GPU 并行映射

GPU 并行方式：

```text
一个 PRT -> 一次 GPU kernel
一个线程 -> 一个距离单元
线程内部 -> 遍历当前 active patch
每个 patch -> RNG + FIR + 分布变换 + 权重叠加
```

这种映射方式利用了距离单元之间相互独立的特点，适合 GPU 并行计算。

### 7.6 二维并行与 K 分布快路径优化

在一维距离并行基础上，进一步设计二维 range x patch 实验路径：

```text
Kernel A: 每个线程计算一个 (距离单元, active patch) 的贡献
Kernel B: 对同一距离单元的多个 patch 贡献进行归约
```

该方法提高了线程级并行度，适合 active patch 数量和 FIR 长度较大时进行对比验证。
初步测试表明，在低端 GPU 上二维并行提升有限，说明主要瓶颈不只来自线程数量不足，
还包括随机数生成、非线性函数计算和 K 分布 texture 更新。

针对 K 分布，进一步加入 AR(1) texture 快路径：

```text
连续 PRT: z[n] = rho x z[n-1] + sqrt(1-rho^2) x e[n]
跳步更新: z[n] = rho^delta x z[n-delta] + sqrt(1-rho^(2delta)) x e[n]
```

由于实际扫描中同一 active patch 多数情况下按连续 PRT 更新，连续 PRT 可直接使用预计算的
`rho` 和 `sqrt(1-rho^2)`，避免每次调用 `pow` 和 `sqrt`。跳步情况仍保留原始公式，
保证模型逻辑不变。

进一步地，连续 PRT 生成可采用异步双缓冲调度：

```text
slot 0 / slot 1 双缓冲
CPU 构建 active patch
cudaMemcpyAsync 上传 active patch
GPU kernel 生成当前 PRT 杂波
cudaMemcpyAsync 回传当前 PRT 回波
CPU 转换上一 slot 的输出
```

对于 K 分布，由于 texture 状态需要按时间顺序更新，相邻 PRT 的 kernel 仍保持顺序执行；
双缓冲主要用于重叠数据传输、CPU 侧 active patch 构建和主机端结果转换。
如果后续分布模型不包含跨 PRT 状态，或后续脉压/检测也放在 GPU 上，可进一步扩大 stream 调度收益。

## 8. 第六部分：验证方法与当前结果

### 8.1 单 patch 幅度分布验证

固定一个距离单元和方位 patch，连续生成大量慢时间样本，验证：

- 瑞利分布直方图。
- Weibull 分布直方图。
- 对数正态分布直方图。
- K 分布重尾特性。

### 8.2 功率谱验证

对单 patch 的 IQ 序列估计功率谱，检查生成序列是否满足设定多普勒谱形。

### 8.3 一圈 PPI 图像验证

生成完整一圈扫描数据，显示：

- 距离-方位功率图。
- PPI 图。
- 指定距离单元一圈 IQ 或功率变化。

### 8.4 实时性验证

通过 benchmark 测试：

- 平均单 PRT 生成时间。
- 每秒生成 PRT 数。
- 实时倍率。
- 不同分布模型耗时对比。
- 不同 FIR 长度耗时对比。
- 不同距离单元数耗时对比。
- 一维距离并行、二维 range x patch 并行、二维 fast 路径对比。
- 同步调用与异步双缓冲连续 PRT 调度对比。

重点平台为 Jetson AGX Orin 32G。
