## 一、汇报定位

本部分面向组会演示，目标不是单纯展示几张结果图，而是回答下面三个问题：

1. 当前仿真系统是否能够让目标随时间推进，而不是重复生成静态回波。
2. 当前海杂波模型是否能够通过海况参数变化体现不同背景强度。
3. 在目标、杂波、噪声同时存在时，是否能够得到适合后续检测与算法验证的可控回波数据。

因此，这部分 PPT 建议采用“两短一总”的组织方式：

- 先做一个动目标验证实验，证明目标位置会随扫描圈更新。
- 再做一个海杂波验证实验，证明改变海况会改变背景杂波强度。
- 最后给出一个综合实验，展示目标处于海杂波背景中的回波结果。

推荐做成 5 页，不要只堆图，每页都需要有“实验目的、参数、现象、结论”。

### 第 3 页：动目标位置更新实验

**页面标题建议**：

`实验一：跨圈目标位置更新验证`

#### 3.1 实验目的

验证仿真系统中的目标状态会随时间推进，而不是在每圈扫描中重复使用静态位置。

#### 3.2 数学模型

匀速目标采用：

```text
p(t) = p0 + v * t
```

系统在每个 CPI 开始前按当前仿真时间更新目标状态，再生成该波位回波。因此只要 `motion_model = ConstantVelocity`，目标位置就应随扫描圈推进。

#### 3.3 代码链路说明

- 在仿真主循环中，每个 CPI 前执行 `target_engine_->update_targets(current_time)`。
- 时间在每个 CPI 后按 `pulses_per_cpi * PRI` 推进。
- 匀速模型中，目标位置由 `init.position_m + init.velocity_mps * current_time_s` 计算得到。

#### 3.4 建议实验设置

- 关闭杂波：`clutter.enabled = false`
- 保留目标与噪声
- 使用当前基线配置：`scan_count = 3`
- 采用 `view.m` 展示多圈数据

#### 3.5 图像峰值与理论距离对比

这张图使用的是 `view.m` 的“跨圈最大保持距离剖面”。图上的 `X` 轴峰值不是连续几何距离，而是目标回波写入采样点以后，再映射到显示距离轴上的结果。因此本页只比较距离位置，不比较幅度。

理论显示距离按下面口径计算：

```text
R(t) = ||p0 + v * t||
t_obs(scan k) ≈ k * T_scan + beam_index * T_CPI
T_CPI = pulses_per_cpi / PRF = 32 / 1600 = 0.02 s
T_scan = beam_count * T_CPI = 180 * 0.02 = 3.6 s

delay_idx = round((2 * (R - min_range) / C) * Fs)
R_plot = min_range + delay_idx * (3e8 / (2 * Fs))
```

其中 `t_obs` 取该圈中波束扫到目标附近的 CPI 时刻，而不是扫描圈起点时刻。

| 目标 | 扫描圈 | 图像峰值距离 (km) | 理论显示距离 (km) | 结论 |
|------|--------|-------------------|-------------------|------|
| 目标 1 | 0 | 4.2775 | 4.2775 | 一致 |
| 目标 1 | 1 | 4.3275 | 4.3275 | 一致 |
| 目标 1 | 2 | 4.3775 | 4.3775 | 一致 |
| 目标 2 | 0 | 5.0200 | 5.0200 | 一致 |
| 目标 2 | 1 | 5.0575 | 5.0575 | 一致 |
| 目标 2 | 2 | 5.0925 | 5.0925 | 一致 |
| 目标 3 | 0/1/2 | 6.9000 | 6.9000 | 三圈重合，静止目标不变 |

连续几何斜距和图像峰值距离相差几米是正常的，因为目标回波先被距离采样点量化，再由 `view.m` 映射到距离轴。当前显示步长为 `3e8 / (2Fs) = 2.5 m`。

本页不对 `Y` 轴幅度做逐点理论对比，因为幅度同时受传播损耗、天线增益、Swerling 起伏、噪声和最大保持处理影响，更适合做趋势说明。

#### 3.6 建议配图

- `view.m` 生成的“跨圈差分图”
- `view.m` 生成的“跨圈距离剖面对比”
- 使用“跨圈最大保持距离剖面”读取图像峰值距离，并和上表理论显示距离对比

不建议只放单圈 P 显，因为单圈图难以直接体现几十米量级的位置变化。

#### 3.7 结论表述

可直接写为：

> 从跨圈最大保持距离剖面可以看出，目标 1、目标 2 的图像峰值距离与理论显示距离一致，并且随扫描圈连续向远距离移动；目标 3 的峰值三圈重合，说明静止目标保持不变。这个结果说明系统确实按仿真时间推进了目标状态，而不是重复绘制静态目标。

### 第 4 页：海杂波海况变化实验

**页面标题建议**：

`实验二：海况变化对海杂波背景的影响`

#### 4.1 实验目的

验证海杂波模型能够通过海况参数变化体现不同的背景强度，从而证明杂波环境是可控的。

#### 4.2 模型说明

当前海杂波后向散射系数采用 Morchin 论文式模型，其中 `morchin_sea_state` 为关键参数。海况等级增加时，海面粗糙度和后向散射系数上升，回波背景会更强。

#### 4.3 建议实验设置

- 开启杂波：`clutter.enabled = true`
- 固定随机种子、扫描参数、目标参数
- 为了突出背景变化，建议本组实验可以先关闭目标，或在讲图时只关注无目标区域
- 推荐只改一个参数：`morchin_sea_state = 1 / 3 / 5`

#### 4.4 当前杂波建模口径

- `grid_mode = 1`，即 `RangeSampleGrid`
- `sequence_mode = 1`，即 `SequencePoolMode`
- `k_shape_nu = 2`
- `doppler_sigma_hz = 50`

这几个参数在本组实验中固定不变，保证观察到的差异主要来自海况等级变化。

#### 4.5 建议配图

- 三张并排 B 显，分别对应 `ss = 1`、`ss = 3`、`ss = 5`
- 或三张并排 P 显，但必须统一色标

#### 4.6 图像讲述重点

- `ss = 1` 时，背景较弱，目标更容易凸显。
- `ss = 3` 时，背景开始增强，海杂波结构更加明显。
- `ss = 5` 时，杂波背景明显抬升，目标更容易被淹没在背景中。

#### 4.7 结论表述

可直接写为：

> 在其余参数保持不变的条件下，仅通过调节 `morchin_sea_state` 即可观察到海杂波背景由弱到强的连续变化，说明海杂波模型具备环境可调性，能够为后续海况相关算法验证提供条件。

### 第 5 页：综合实验结果与结论

**页面标题建议**：

`实验三：目标、海杂波与噪声综合场景`

#### 5.1 实验目的

在统一场景下同时展示目标运动、海杂波背景和噪声叠加效果，体现仿真平台的综合建模能力。

#### 5.2 建议实验设置

- `target.enabled = true`
- `clutter.enabled = true`
- `noise.enabled = true`
- 海况取中等水平：`morchin_sea_state = 3`
- 其余参数沿用基线配置

#### 5.3 建议配图

- 一张综合 B 显或 P 显，体现“目标处于杂波背景中”
- 一张跨圈差分图，体现“目标仍在跨圈移动”

#### 5.4 这一页建议总结三点

1. 系统生成的图像峰值距离与理论显示距离一致，说明目标状态确实按时间推进，而不是静态不变。
2. 系统可以通过海况参数控制海杂波背景强弱。
3. 在目标、海杂波、噪声同时存在时，仍能得到结构清晰、可分析的综合回波数据。

#### 5.5 最后一行建议写法

> 该仿真平台基于理想相控阵波束级模型和统计海杂波模型，能够生成包含目标运动、海杂波环境变化和噪声扰动的可控回波数据，为后续目标检测、杂波抑制和信号处理算法验证提供实验基础。

## 五、答辩/组会时可直接使用的话术

### 5.1 开场话术

> 本次实验主要验证两个动态特性：一是目标是否会随仿真时间推进，二是海况变化是否会体现在海杂波背景变化上。为了避免只展示静态图像，我把实验拆成了动目标验证、海杂波验证和综合场景三部分。

### 5.2 参数页话术

> 参数页我没有按代码模块去讲，而是按实验逻辑分成四类：体制参数决定分辨率和采样精度，扫描参数决定时间窗口，目标参数决定运动状态，杂波参数决定背景强度和起伏特性。这样后面的实验现象就能直接和参数对应起来。

### 5.3 动目标实验页话术

> 在这个实验里我先关闭海杂波，只保留目标和噪声，目的是单独验证目标状态更新链路。这里我不直接拿连续斜距去对图，而是把图像上的峰值距离和离散显示后的理论距离做对比。可以看到目标 1、2 在三圈中的图像峰值与理论显示距离一致，并且持续向远距离移动；静止目标三圈重合，说明系统确实在按时间推进目标状态。

### 5.4 海杂波实验页话术

> 在这组实验中，我固定扫描参数和随机种子，只改变海况等级 `morchin_sea_state`。从结果可以看到，海况升高后，杂波背景明显增强，这说明当前海杂波模型具备环境可调性。

### 5.5 结尾话术

> 综合来看，当前系统已经可以同时体现目标运动更新和海杂波环境变化。这里我更愿意把它表述成一个工程级、可控参数、可解释的回波仿真平台，而不是高保真真实相控阵全链路仿真。对于当前的检测、抑制和可视化验证任务，它已经是够用的。

## 七、建模边界与真实性说明

这一部分不一定要放到主 PPT 正页里，但建议至少准备成答辩备注或附页。这样既能说明当前实验为什么成立，也能避免把模型口径讲得过满。

### 7.1 当前方法能支撑的结论

- 目标会随扫描时间推进，图像位置会变化。
- 海情参数会改变海杂波背景强弱。
- 在目标、杂波、噪声同时存在时，可以得到可控、可解释的回波数据。

### 7.2 当前方法不能直接宣称的内容

- 不宜表述成“高保真真实相控阵雷达全链路仿真”。
- 不宜暗示“真实海面散射机理已经完整建模”。
- 不宜把当前结果直接外推为“真实舰船/海面细节散射特征已经可信”。

### 7.3 目前最主要的原理性缺口

#### 1. 相控阵真实性不足，当前更像理想波束级模型

- 当前天线更接近理想阵因子扫描模型，主要体现波束方向和理想增益。
- 没有显式建模阵元方向图、互耦、通道幅相误差、扫描损失、宽带波束偏斜、子阵结构和校准误差。
- 当前输出是“每个波位一个合成后的波束通道”，不是阵元级或子阵级接收数据。

这一点决定了：现在可以讲“电子扫描波束下的回波生成”，但不能讲“真实相控阵接收链/波束形成/STAP 级仿真”。

#### 2. 几何模型还是局部雷达坐标系近似

- 当前目标距离、方位、俯仰本质上按雷达原点局部坐标计算。
- 缺少统一的“雷达平台位置/姿态 + 目标世界坐标”口径。
- 还没有地球曲率、地平线遮蔽、海面起伏几何、平台摇摆/俯仰/横滚这些因素。

对当前 1 到 10 km、低高度、概念验证级实验来说，这个近似是可接受的；但如果后续要讲“真实海面监视几何”，它会成为明显短板。

#### 3. 目标模型仍然是点目标散射中心近似

- 当前目标主要是单散射点回波加 Swerling 起伏。
- 没有扩展目标、多散射中心、姿态变化、微动、桅杆/舰体多点结构、遮挡闪烁。
- 目标多普勒主要来自质心运动，还不足以代表真实舰船或低空目标的谱展宽和微多普勒。

因此现在更适合验证“目标位置变化”和“杂波背景下可见性”，不适合直接用于精细分类、微动特征或舰船结构成像类结论。

#### 4. 海杂波是统计模型，不是海面散射机理模型

- 当前海杂波核心可以概括为：`Morchin sigma0 + K 分布幅度起伏 + 高斯多普勒谱`。
- 这是工程上常见、可用的统计建模方法，但不是从海面波谱和散射机理直接生成。
- 目前还没有风速/风向、海浪传播方向、极化、掠海入射角细化、海尖峰、破碎浪、非高斯空间相关等关键因素。

因此现在可以讲“海情可调的统计海杂波背景”，但不能讲“真实海况驱动的物理海面散射仿真”。

#### 5. 海杂波时间连续性和空间相关性还不够真实

- 现在的慢时间相关性主要靠每个单元的相关序列和统一谱宽控制。
- 跨扫描圈、跨相邻波位、跨距离/方位单元的联合连续演化还不完整。
- 尤其在多圈实验里，真实海面应当是连续演化的，而不是各个单元各自截取一段统计序列。

这对单圈背景展示和海情强弱对比影响不大，但对长时稳定跟踪、时空杂波谱演化和跨圈一致性分析会有影响。

#### 6. 接收链和系统误差基本没有进入模型

- 当前更像理想基带回波叠加。
- 缺少本振相位噪声、频率误差、采样时钟偏差、AGC、量化、通道不一致、脉压失配、杂散和旁瓣污染。

这会让结果在“看现象”上更干净，但也比真实系统更乐观。

### 7.4 组会时更稳的表述

#### 可以直接讲的

- 当前这是一个工程级、可控参数、可解释的海杂波背景回波仿真平台。
- 当前实验重点验证两件事：目标状态随时间推进、海情参数可调节背景强弱。
- 对目标检测、杂波抑制、数据流程联调和可视化验证是够用的。

#### 更稳的术语

- “当前采用的是理想相控阵波束级模型 + 统计海杂波模型”
- “该平台适合开展目标运动、背景强弱和检测可见性方面的实验验证”
- “后续可继续向阵元级接收链、海面机理散射和长时连续演化扩展”

## 八、后续升级路线

如果后续要把它逐步推向更高真实性，可以按下面顺序升级。这里的顺序是按“对当前实验结论的影响大小”排序，不是按实现难度排序。

### 优先级 1：补齐相控阵层级

- 从单波束输出扩展到阵元级或子阵级输出。
- 引入阵元方向图、通道幅相误差、扫描损失和宽带扫描效应。

这是提升“相控阵真实性”最大的步骤。

### 优先级 2：统一观测几何

- 明确雷达平台坐标、目标世界坐标、天线高度/姿态和海面参考面。
- 把目标和杂波统一到同一套 `slant range / az / el` 几何口径下。

这是提升“模型物理一致性”最关键的一步。

### 优先级 3：增强海杂波连续演化

- 让同一海面单元在跨 CPI、跨扫描圈中连续推进，而不是按当前统计片段近似。
- 再增加相邻方位/距离单元的空间相关。

这是提升“长时序真实性”最关键的一步。

### 优先级 4：增强目标散射真实性

- 从点目标升级到多散射中心或扩展目标。
- 引入姿态变化、微动、多普勒展宽和 aspect-dependent RCS。

这是后续做分类与识别类任务时最需要补齐的部分。

### 8.1 后续验证建议

- 若后续升级相控阵层级，应至少验证阵元级输出与波束级输出的一致性，以及扫描角增大时的增益下降和波束展宽。
- 若后续升级海杂波连续性，应至少验证不同海情下平均距离剖面整体抬升，以及同一方位/距离单元跨圈演化连续而不是重置。
- 若后续升级目标真实性，应至少验证扩展目标在距离像/多普勒像上不再等价于单点目标，以及姿态或微动变化能体现在谱结构中。
