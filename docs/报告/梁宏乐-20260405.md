## 二、目标回波模块实现

上周代码中没有目标回波模块，本周新增完整的 target 模块，实现点目标回波生成逻辑。

### 2.1 模块架构

```
TargetEngine (统一管理器)
  ├─ TargetManager (目标状态管理)
  ├─ TargetKinematics (运动学计算)
  └─ TargetEchoSynthesizer (回波合成)
```

### 2.2 TargetManager - 状态管理

**功能**：管理目标状态，支持运动模型外推

**运动模型支持**：
- `Stationary`：静止目标
- `ConstantVelocity`：匀速目标
- `ConstantAcceleration`：匀加速目标
- `VariableAcceleration`：变加速目标

**关键接口**：
```cpp
void set_targets(const TargetList& targets);       // 设置初始目标
void update_to_time(Scalar current_time_s);        // 更新到指定时刻
const TargetList& get_current_targets() const;     // 获取当前状态
```

### 2.3 TargetKinematics - 运动学计算

**功能**：生成目标在 CPI 内的逐脉冲轨迹快照

**计算内容**：
- 位置外推（运动学方程）
- 几何量计算：距离、径向速度、径向加速度
- 波束增益调制（天线方向图）
- Swerling RCS 起伏模型

**Swerling 起伏支持**：
| Swerling 类型 | 分布特性 | 起伏速度 |
|--------------|---------|---------|
| Swerling0 | 不起伏 | - |
| Swerling1 | 指数分布 | 慢起伏（CPI内不变） |
| Swerling2 | 指数分布 | 快起伏（脉冲间变化） |
| Swerling3 | 卡方分布(4自由度) | 慢起伏 |
| Swerling4 | 卡方分布(4自由度) | 快起伏 |

### 2.4 TargetEchoSynthesizer - 回波合成

**功能**：将目标轨迹转换为 IQ 回波数据

**处理流程**：
1. 计算距离延迟 → 确定回波起始位置
2. 相位调制：φ = -4πR/λ（双程相位）
3. 幅度调制：雷达方程计算或简化模式
4. 将发射波形叠加到对应距离单元

**雷达方程（可选）**：
$$
A = \sqrt{\frac{P_t G^2 \lambda^2 \sigma}{(4\pi)^3 R^4 L_s}}
$$

## 三、仿真主循环集成

### 3.1 主循环结构

重构为两层循环（scan → cpi）：

```cpp
for (int scan = 0; scan < total_scan_count_; ++scan) {
    for (int beam = 0; beam < beam_count_; ++beam) {
        // 处理单个 CPI
        process_single_cpi(cpi_index, current_time, ...);
    }
    process_scan_complete(scan, ...);  // 每圈扫描独立导出
}
```

### 3.2 单 CPI 处理流程

`process_single_cpi()` 实现：

1. **获取波位**：`beam_scanner_->get_beam_pointing()`
2. **更新目标状态**：`target_engine_->update_targets(current_time)`
3. **获取发射波形**：`waveform_gen_->get_waveform()`
4. **生成目标回波**：`target_engine_->generate(...)`
5. **生成杂波回波**：`clutter_engine_->generate_sea_clutter_cpi(...)`
6. **合成总回波**：目标 + 杂波
7. **添加噪声**：`noise_engine_->add_noise(total_echo)`
8. **UDP 发送**：实时数据传输

### 3.3 五路模块集成

| 模块 | 类 | 功能 |
|-----|-----|------|
| 波形 | WaveformGenerator | 产生发射波形（LFM/NLFM/相位编码） |
| 天线 | BeamScanner + AntennaModel | 波位管理、增益计算 |
| 目标 | TargetEngine | 目标状态管理、回波生成 |
| 杂波 | ClutterEngine | 海杂波回波生成 |
| 噪声 | NoiseEngine | 复高斯白噪声添加 |
