## 二、本周主要工作

### 2.1 海杂波模型修正与验证口径统一

本周将海杂波后向散射系数统一为论文式 Morchin 公式，实现与文档口径一致：

- 代码层：修正 `SeaClutterModel` 中 Morchin 计算逻辑，统一 `sea_state` 参与方式。
- 配置层：保留 `sea_state`、`k_shape_nu`、`doppler_center_hz`、`doppler_sigma_hz` 等关键参数，便于可控实验。
- 文档层：更新 `docs/validation/clutter-validation-guide.md`，将经验式描述替换为论文式表达。
- 工具层：`app/clutter_validation.cpp` 输出 `morchin_sigma0.csv`、`k_distribution_samples.csv`、`doppler_spectrum.csv`，用于 MATLAB 对比。

### 2.2 SeaClutter 双层建模与一致性回归增强

本周围绕“可解释 + 可回归”目标，增强了海杂波双层建模验证：

- 建模结构：
  1. 几何/功率层：按网格计算单元平均回波功率。  
  2. 统计起伏层：K 分布（SIRP）+ 高斯多普勒谱生成慢时间复序列。
- 模式支持：
  - 网格模式：`PhysicalGrid` 与 `RangeSampleGrid`
  - 序列模式：`InTimeMode` 与 `SequencePoolMode`
- 回归测试增强（`test/radar_tests.cpp`）：
  - Morchin 掠射角趋势验证（`1° -> 89°` 单调上升）
  - 海况分层验证（同掠射角下高海况强于低海况）
  - 临界角连续性验证（`phi_c` 附近数值连续、有限、正值）
  - 双网格 + 双序列严格等价回归（`max_diff <= 1e-9`）
  - K 分布拖尾特性与随机种子重复性验证

### 2.3 综合实验与汇报材料整理

围绕组会展示，完成“动目标-海杂波-综合场景”三组实验材料整理（文稿：`docs/报告/梁宏乐-20260416-PPT实验介绍.md`）：

1. 动目标跨圈更新实验（3 圈扫描）
- 目标 1：`4.2775 -> 4.3275 -> 4.3775 km`
- 目标 2：`5.0200 -> 5.0575 -> 5.0925 km`
- 目标 3：`6.9000 km`（三圈重合）
- 结论：目标状态按仿真时间推进，非静态重复绘制。

2. 海况变化实验（固定其余参数，仅改 `sea_state`）
- `ss=1`：背景较弱
- `ss=3`：背景增强
- `ss=5`：背景明显抬升
- 结论：海情参数可连续调节杂波背景强弱。

3. 综合场景实验（目标 + 杂波 + 噪声）
- 在统一参数下可获得结构清晰、可分析的综合回波数据。
- 支撑后续检测、杂波抑制与算法联调验证。
