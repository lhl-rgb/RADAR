### 2.1 波形生成模块验证

**验证内容**：

- 匹配滤波器共轭反转验证
- 功率归一化验证

**测试方法**：

1. **LFM 波形验证**
   - 参数：B=20MHz, T=20μs, fs=40MHz, N=800

   - 参数：B=20MHz, T=20μs, fs=40MHz, 窗函数=Hamming

### 2.2 天线模块验证

**验证内容**：
- ULA/UPA 阵因子计算正确性
- 波束扫描功能验证
- 加权类型（Uniform/Hamming）验证
- 与 MATLAB 增益计算对比

**数学模型**：
```
ULA: ψ = 2π(d/λ)(sinθ - sinθ₀)
     AF = Σ w[n]·exp(j·n·ψ)

UPA: u = cos(el)·sin(az), v = sin(el)
     AF = ΣΣ wx[m]·wy[n]·exp(j·(m·ψx + n·ψy))
```

**测试方法**：

1. **ULA 一维方向图对比**
   - 参数：N=16, d/λ=0.5, G_peak=30dB, 波束指向θ₀=10°

2. **UPA 二维方向图对比**
   - 参数：N_az=16, N_el=16, d/λ=0.5, G_peak=35dB
   - 方位扫描：-60° ~ +60°，俯仰扫描：-30° ~ +30°
   - 生成二维增益热力图进行直观对比

3. **波束扫描控制器验证**

### 2.3 噪声模块验证

**验证内容**：
- 复高斯白噪声生成（I/Q 独立性）
- 三种噪声模式（ComplexSigma/NoisePower/ThermalKTB）
- 加噪后 SNR 验证
- 随机种子重复性

**噪声功率计算**：
```
ThermalKTB: Pn = k·T·B·F
  k = 1.380649e-23 J/K
  T = 噪声温度 (K)
  B = 带宽 (Hz)
  F = 噪声系数 (线性值)
```

**测试方法**：

1. **ComplexSigma 模式验证**
   - 参数：σ=0.001, N=100000
   - 验证理论功率：Pn = σ²
   - 验证 I/Q 分量标准差：σ_IQ = σ/√2

2. **NoisePower 模式验证**
   - 参数：Pn=1e-6W, N=100000
   - 验证生成噪声的平均功率统计

3. **ThermalKTB 模式验证**
   - 参数：T=290K, B=10MHz, NF=4dB
   - 验证热噪声功率计算：Pn = kTB·F

4. **SNR 验证**
   - 参数：信号功率=100×噪声功率 → SNR=20dB
   - 验证加噪后实测 SNR 与理论值对比

5. **多 SNR 点验证**
   - 测试点：-5, 0, 5, 10, 20, 30 dB

**测试结果**：75/75 测试通过

| 测试项 | 通过标准 | 实测值 | 状态 |

| ComplexSigma 功率误差 | < 0.5% | 0.13% | ✅ PASS |
| I/Q 标准差误差 | < 0.5% | 0.08% | ✅ PASS |
| NoisePower 功率误差 | < 0.5% | 0.21% | ✅ PASS |
