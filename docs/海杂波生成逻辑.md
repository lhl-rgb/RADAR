# 海杂波生成逻辑（双层建模）

## 1. 模块职责
- `SeaClutterModel`：海杂波生成器，负责一个 CPI 的海杂波原始回波生成（`clutter-only`）。
- `ClutterEngine`：杂波管理层，当前封装 `SeaClutterModel`，后续可扩展其他杂波类型。

## 2. 输入与输出
- 输入：
  - `RadarParams`
  - `PhasedArrayAntenna`
  - 当前波位 `AzEl beam_pointing`
  - `beam_index`
  - 发射时域波形 `ComplexVec tx_waveform`
- 输出：
  - `CpiEcho out_clutter`（维度：`pulses_per_cpi x samples_per_pulse`，仅海杂波）

## 3. 双层建模流程

### 3.1 平均功率层（几何 + 雷达方程）
1. 以当前波位为中心建立扇形网格：
   - 地距维：`Rg in [Rg_min, Rg_max)`，步长 `dR`
   - 方位维：覆盖宽 `beam_az_width_deg`，步长 `dAz_deg`
2. 每个网格单元计算几何量：
   - `R = sqrt(h^2 + Rg^2)`（斜距）
   - `psi = atan2(h, Rg)`（掠射角）
   - `A = Rg * dR * dAz(rad)`（单元面积）
3. Morchin 参数化模型：
   - `sigma0_db = a0_db + a_g*log10(max(sin(psi), sin_psi_floor)) + a_f*log10(fc_GHz) + a_s*sea_state`
   - `sigma0 = 10^(sigma0_db/10)`
4. 单元 RCS 与平均接收功率：
   - `sigma_cell = sigma0 * A`
   - `Pr_cell = Pt * Gtx * Grx * lambda^2 * sigma_cell / ((4*pi)^3 * R^4 * L)`
   - 其中 `Gtx/Gtx` 来自当前天线模型对该单元方向的增益。

### 3.2 统计起伏层（慢时间）
1. 先构造单位平均功率复序列 `g[n]`：
   - 频域高斯谱：`S(f)=exp(-0.5*((f-f0)/sigma_f)^2)`
   - 频域塑形后逆 DFT（内部 O(N^2)）
   - 归一化：`mean(|g|^2)=1`
2. K 分布幅度起伏（SIRP）：
   - `tau[n] ~ Gamma(nu, 1/nu)`
   - `x[n] = sqrt(tau[n]) * g[n]`
   - 再归一化到单位平均功率

### 3.3 两种随机策略
- `InTimeMode`：
  - 每个散射单元按 `(seed, beam_index, range_idx, az_idx)` 确定性播种。
  - 回归测试强可复现，适合验证与并行。
- `SequencePoolMode`：
  - 先生成长序列池（`pool_length_factor * pulses_per_cpi`）。
  - 每个单元随机起点截取一个 CPI 长度序列（循环取样）。
  - 同 seed 下可复现，不同单元一般不同起点。

### 3.4 回波合成
1. 参考时延：
   - `tau_ref = 2*sqrt(h^2 + Rg_min^2)/c`
2. 单元快时间起点（最近邻）：
   - `n0 = round((2*R/c - tau_ref) * fs)`
3. 对每个脉冲叠加：
   - `out[p][n0+m] += sqrt(Pr_cell) * x[p] * tx_waveform[m]`
   - 越界按快时间窗口裁剪。

## 4. 参数口径
- 地距口径：海杂波网格范围使用地距 `Rg`。
- 方位覆盖：`beam_az_width_deg` 表示当前波位下的方位覆盖宽度（通常按天线方位波束宽度设置）。
- 发射波形：由外部传入，`SeaClutterModel` 接受任意 `ComplexVec`。
